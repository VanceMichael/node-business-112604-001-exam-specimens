# 合成资料的字段

体积以 ml 的十进制字符串表示；minMl 是该项一次检验所需用量，maxHours 从实际采集时间起算。conditions 是采集人员确认的条件。sampleId 在中心内唯一，子管还需记录 parentSampleId 和实际分装量；项目与来源标本不能只按受检者姓名关联。金额以分记录，result 的 revision 只在同一委托项目内递增。

`catalog.json` 是静态领域目录，`records.json` 是独立的业务输入记录。每条记录有唯一 `recordId`、事件类型 `kind` 和输入内容 `payload`；它不是接口路径约定，也不包含自动判定的处理结果。同一类型可以再次输入其他符合字段含义的数据。发生时间有具体字段时以该字段为准，输入先后不能代替发生先后。

资料中的版本在所属来源或业务对象内比较，不能跨来源按数字大小合并。文件顶层 `synthetic` 表示合成性质。业务记录中引用的新申请或新回执标识在该条输入时引入，不要求它们预先出现在静态目录。中文文本用于说明输入事实，所有可识别身份均非真实人员。
